已经形成的保护

  • 默认拒绝缺关键认证配置启动失败；空 allowed 名单拒绝访问。
  • Cookie 边界Secure、HttpOnly、SameSite=Lax；飞书 token 不进入 Cookie。
  • 数据库门禁不考虑必填理由、状态变化日志、人工与机器写入面分离。
  • actor 留痕页面把姓名与 open_id 后八位写入 updated_by。

当前安全边界

  • 共享池任一 writer 可修改任一卡片；owner 不是权限字段，无 RLS / tenant。
  • 共享 DB 身份数据库只看到 voc_human，不能可信地区分具体飞书用户。
  • 写路径枚举中间件依赖已知 POST 路径正则；新增写路由若漏登记存在 fail-open 风险。
  • 会话吊销无服务端 session 表；单独吊销依赖移出名单并重启，整体吊销依赖轮换 secret。
飞书当前只负责身份。 已实现 OAuth 换 token、获取用户资料、读写白名单和操作人文本；没有机器人消息、交互卡片、普通提醒、应用内 / 短信 / 电话加急或送达回执。任何 SLA 通知均属于产品规划。

核心术语
消息
一条上游用户内容，以 message_id 为全局身份。
证据
消息按平行标签数组展开后的最小可追溯单元，以 message_id + seq 标识。
事实 SPU
云听直接标注的产品编号；与推断的根帖继承 SPU 分列。
冻结归属
某个 run_id 下把一条证据分配给具体 SPU 的不可变扇出键。
产品机会
OPP2 稳定实体；老品代表具体 SPU 的失效模式，新品代表无现有产品归属的诉求。
终态
证据不能或不应形成机会时的明确结局，不等同于系统失败。
提案
机器发现可能的合并、拆分、复活或重写时，交给有限执行 / 人工裁决的变更对象。
战略轴
在基础机会之上的跨卡读模型，用于呈现跨 SPU 通病或多卡诉求主题。
backlog
机器层的放行标记；目前不是 per-PM 批阅任务或 SLA 状态。
finalize
双生命周期成功后执行的守恒、快照、派生刷新与放行步骤集合。
事实来源优先级 当前 SQL / Python 与正式运行入口→契约测试→最新构建 / 运维报告→README 与历史规格
